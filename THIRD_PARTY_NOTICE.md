# Design source and attribution

The mechanical iris used in this course project was based on **Mechanical Iris by sketchpunk**: https://www.thingiverse.com/thing:773759

The downloaded source folder contains a `LICENSE.txt` stating: “This thing was created by Thingiverse user sketchpunk, and is licensed under Creative Commons - Attribution - Non-Commercial”. It does not state a license version. The 3D model was manually recreated and adapted for the course prototype; the report describes changes to the stepper motor mount, the gear and the iris leaves.

The project report is jointly authored by **Piotr Trusiewicz and Michał Pietrzak**. Images extracted from it are shown here as records of our prototype and tests. This repository does not grant permission to use the original design commercially or to remove its attribution.
